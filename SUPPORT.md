# Support

Use [Jeryu issues](https://github.com/neverhuman/jeryu/issues) for installation
problems, reproducible defects, feature requests and documentation corrections.
Check the [quick start](README.md) and [current status](docs/migration/STATUS.md)
first; this monorepo is still a release candidate.

Include the exact Git commit or release, platform, command, expected behavior
and actual error. For browser reports, include the browser version and the
affected operation. Share only the smallest sanitized log or reproduction
needed to explain the problem.

Never attach tokens, bootstrap passwords, private repositories, `.work`,
runtime exports or a full data directory. For suspected vulnerabilities,
follow [SECURITY.md](SECURITY.md).

Support is provided through repository maintenance. No response-time or hosted
service availability commitment is published. Component questions and fixes
should be routed through this monorepo so they remain connected to the shared
build, audit and release process.
