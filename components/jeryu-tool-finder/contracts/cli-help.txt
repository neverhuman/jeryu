Cross-repo duplicate-code discovery: scan, dossier, and propose shared tools

Usage: jeryu-tool-finder <COMMAND>

Commands:
  scan     Scan for cross-repo repeated-code clusters and write dossiers/clusters.json
  dossier  Enrich scanned clusters into agent-readable tool-candidate dossiers
  propose  Promote a dossier into a jeryu-tool registry proposal + build task
  summary  Print the sibling jeryu-tool registry summary (delegates to its owner)
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
