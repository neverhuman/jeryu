# jeryu-tool-finder Agent Instructions

The **tool-discovery** arm of the Jeryu split family: scan every repo (one
family or the WHOLE system), cluster code repeated across more than one repo,
and propose the strongest clusters as reusable tools into `jeryu-tool`.

Before editing, read `README.md` and `docs/tool-finder.md`.

This repo is **all Rust** (a single `jeryu-tool-finder` binary under `src/`).
The cross-repo cluster engine lives in `jeryu-intelligence/crates/jeryu-codegraph`
and is consumed **as a library** from the immutable
`jeryu-intelligence-v5.0.0-split.1` source identity. That historical Cargo URL
spelling stays stable while governed longest-prefix rewrites carry the bytes
over `git.neverhuman.org`; relative Cargo patches and ambient sibling checkouts
are forbidden. One engine implementation serves this CLI, the dashboard, and
MCP, so cluster ids and LOC numbers always agree.

The pipeline is `scan → dossier → propose`. `scan --system` covers every split
family on the host (gitignore-aware discovery, overlap merging, categories,
pattern families); the default scope is the family in `--manifest`. `propose`
MUTATES the sibling `jeryu-tool` repo (registry entry + build task); keep its
output valid against `jeryu-tool`'s Rust-backed `ops/registry-summary.sh --check`.

`dossiers/` is a generated zone (regenerated by `just scan && just dossier`); do
not hand-edit or commit its contents. Required local commands are `just check`,
`just score`, `just security`, `just contract-drift`, and `just artifact-support`;
`just` runs the full product gate. There is no `fast` lane here — the jankurai
pin is owned by `jeryu-tool`, not this repo.

## Docs index

Durable detail lives in agent-readable docs, routed from here:

- `docs/architecture.md` — components, boundaries, and the discovery data flow.
- `docs/tool-finder.md` — dossier schema, pipeline, and the LOC-saved definition.
- `docs/testing.md` — the CI lanes, the pipeline tests, and CI/local parity.
- `docs/release.md` — version source, the release gate, integrity, and rollback.
- `CHANGELOG.md` — release notes.
- `ops/AGENTS.md` — the CI-gate cell: owns / forbidden / proof-lane guidance.

Machine-readable routing: `agent/owner-map.json` (who owns each path),
`agent/test-map.json` (the proof route for each path), `agent/proof-lanes.toml`
(the lanes), `agent/boundaries.toml` (the public-portal profile carrying the Rust finder), and
`agent/generated-zones.toml` (the `dossiers/` generated zone).
