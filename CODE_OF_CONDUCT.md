# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal
appearance, race, caste, color, religion, or sexual identity and orientation.

## Enforcement

Report unacceptable behavior through the contacts in [SECURITY.md](SECURITY.md)
and [SUPPORT.md](SUPPORT.md). Do not include vulnerability details in a public
issue. Private vulnerability reporting is used when GitHub has it enabled for
this repository; otherwise open a minimal public issue with no exploit details.

This is not a claim of formal GA, hosted moderation staff, or 24-hour response.
